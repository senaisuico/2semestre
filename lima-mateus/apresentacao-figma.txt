Figma
- Menu da esquerda é chamado layers
- Menu da direita é chamado de sidebar - usado para alterar propriedades do elemento selecionado
- Barra de ferramentas é a barra que fica na parte inferior da plataforma
- Canvas - é o palco onde montaremos nossos projetos/layouts

Barra de Ferramentas.
- Nunca usar o retângulo para construir o próprio layout. Usar a ferramenta quadro(Frame) - Usar o frame que trás as medidas prontas dos diferentes dispositivos
- Section - Ajuda a agrupar as coisas ou elementos específicos
- Slice - é uma tesoura que serve para recortar, mas não é muito boa
- Shapes (Formas) - É possível importar imagens e vídeos (vídeos somente versão pro)
Ao apertar o shift com a ferramenta shape, mantém-se a proporção
- Canetas (Pen e Pencil) - Usado para desenhar uma forma ao invés de criar com shapes. Ao apertar o shift ele cria uma linha reta
- Text - Ferramenta de texto. É possível importar fontes externas 
Obs: Nica fazer a quebra de texto usando o enter - sempre redimensionar a caixa onde o texto está até encontrar a quebra de texto adequada e deixar a borda da caixa o mais próxima possível do texto
- Ferramenta de comentários - Usada para fazer comentários para outras pessoas que irão trabalha no projeto
- Actions (Usado para pegar plugins no Figma)

 


Atalhos 
M (Mover) - move elemento
H (Ferramenta da mão) - usada para mover o canvas
K (Escala) - Aumenta tudo proporcionalmente (Usado para mover um elemento com texto dentro, por exemplo)
F (Frame - Quadro)
Ctrl + K (Actions)
Shift + G (Ativa e desativa o grid no wireframe)
Ctrl + G (Agrupa elementos selecionados no wireframe)
Alt (Quando um elemento está selecionado, apertar o Alt, faz com que ele informe a distância de outros elementos)
